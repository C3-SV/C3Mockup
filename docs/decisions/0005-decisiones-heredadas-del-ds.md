# 0005 · Decisiones heredadas del paquete del DS
- **Fecha:** 2026-10-26 a 2026-11-11 (según cada fila) · **Estado:** aceptada (adoptadas tal cual)

Registradas en el traspaso (§11) a partir de la documentación interna de la plataforma Challenges (demo no lanzado). **Este repo las adopta salvo lo que [ADR-0006](0006-vocabulario-y-color-del-sitio-principal.md) reemplaza:** el término «challenge» y la regla de acción por producto.

| Fecha | Decisión |
| --- | --- |
| 2026-10-26 | «Challenge» es el término oficial en la interfaz |
| 2026-11-04 | Rediseño: acción violeta, cabecera blanca con «Conoce C3», voz «tú», sin aviso global de demo, DEMO por elemento. Colores de línea sin cambios |
| 2026-11-04 | Portadas por enlace: solo hosts de C3, descripción obligatoria, sin subida de archivos |
| 2026-11-05 | Regla de acción: cada producto usa una variante de su línea. C3 Challenges (Conecta) es morado |
| 2026-11-11 | Confirmado el uso de los plugins `design` y `frontend-design` en el diseño del sistema |

**Principio:** un cambio de token o regla se registra aquí con fecha y responsable.
